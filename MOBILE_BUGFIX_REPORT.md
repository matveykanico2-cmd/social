# Mobile bugfix report

В текущем web runtime сохранены адаптивная навигация, безопасные modal/options-menu компоненты, `dvh`-высоты и touch-доступность основных действий. Production build подтверждает отсутствие TypeScript/hydration ошибок в текущем дереве.

Проверка должна выполняться на viewport 320, 360, 375, 390, 414, 430 и 768 px. Автоматические Playwright-тесты в репозитории пока не подключены, поэтому визуальная матрица этих размеров остаётся ручным QA-пунктом, а не заявляется как выполненная.

Открытые пункты: полноценные bottom sheets для всех меню, клавиатурные сценарии iOS/Android, реальное WebRTC на двух клиентах и screenshots regression suite.
