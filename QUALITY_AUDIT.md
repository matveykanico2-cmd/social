# Quality audit

Дата: 2026-11-26.

## Прошло

- ESLint.
- TypeScript (`npx tsc --noEmit`).
- 66 тестов Vitest в 7 файлах.
- `next build`.
- 63 маршрута Next.js собраны.
- Рабочее дерево после коммита проверяется через `git diff --check`.

## Проверенные критические контракты

- Единая авторизация через HTTP-only `sg_session` cookie.
- Миграции SQLite выполняются идемпотентно.
- Загрузка медиа проходит через авторизованные API и сохраняется в серверном upload storage.
- Удаление комментариев очищает прикреплённый локальный файл.
- Данные сообщений, реакций, read state и last-seen хранятся в БД.

## Ограничения приёмки

Реальные звонки между двумя браузерами, TURN, RTMP, S3, native clients, OAuth/2FA и полноценный WebSocket требуют внешней инфраструктуры и не считаются проверенными только по наличию UI.
