# Quality audit

Дата: 2026-11-26.

## Прошло

- ESLint.
- TypeScript (`npx tsc --noEmit`).
- 73 теста Vitest в 11 файлах.
- `next build`.
- 70 маршрутов Next.js собраны.
- Рабочее дерево после коммита проверяется через `git diff --check`.

## Проверенные критические контракты

- Единая авторизация через HTTP-only `sg_session` cookie.
- Миграции SQLite выполняются идемпотентно.
- Загрузка медиа проходит через авторизованные API и сохраняется в серверном upload storage.
- Содержимое разрешённых файлов проверяется по сигнатуре до записи; критичные входы и 2FA-действия попадают в audit log.
- Удаление комментариев очищает прикреплённый локальный файл.
- Данные сообщений, реакций, read state и last-seen хранятся в БД.
- Typing state хранится в отдельной таблице с истечением через 4 секунды и очищается при отправке/остановке ввода.
- Архив чата хранится персонально для пользователя и исключает диалог из основного списка без удаления сообщений.

## Ограничения приёмки

Реальные звонки между двумя браузерами, TURN, RTMP, S3, native clients, OAuth/passkeys и полноценный WebSocket требуют внешней инфраструктуры и не считаются проверенными только по наличию UI. TOTP проверяется unit-тестами и через API-контракт, но требует ручного теста с приложением-аутентификатором.
